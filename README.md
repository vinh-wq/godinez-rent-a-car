# Godínez Rent a Car
1. `npm install` 2. `npm run dev` (http://localhost:3000) 3. `npm run build` para producción.
- Número de WhatsApp, teléfonos, tarifa e Instagram: `lib/config.js`
- Vehículos: `lib/vehicles.js` (fotos en `public/vehicles`)
- Las fotos actuales están recortadas del arte que enviaste: reemplázalas por fotos reales.
